## Publish free using Cloudflare Pages (drag and drop)
1. Open https://dash.cloudflare.com/ and create/sign in to an account.
2. Go to **Workers & Pages**.
3. Choose **Create application** / **Pages** and select the direct-upload or drag-and-drop option (labels may vary).
4. Upload this ZIP file or the unzipped website folder.
5. Give the project a name and deploy it. Cloudflare will provide a `*.pages.dev` web address if available.
6. Open the provided address and test the links on both mobile and desktop.

Official guide: https://developers.cloudflare.com/pages/get-started/direct-upload/

## Later add a .com domain
Buy the domain when you're ready, then use Cloudflare Pages' custom-domain settings to connect it. A `.com` domain normally has a separate registration/renewal cost; you do not need to buy it to deploy this site on the free Pages address.

## Before sharing publicly
- Confirm the address and phone number are correct.
- Test the WhatsApp and Instagram links.
- Add actual product photos, product names, pack sizes, prices, and service details if you want those shown. The current page deliberately invites customers to ask rather than claiming specific product types, prices, or service packages.
- This is a static website; it does not include a booking database, admin dashboard, payment processing, or an enquiry form that stores submissions. WhatsApp is used for enquiries.
